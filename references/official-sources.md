# Official source starting points

Check these sources at the time of the project. Platform rules, category scope, interface behavior, and filing requirements can change. Prefer the logged-in Mini Program console and official documentation over search snippets, copied articles, or old forum answers.

## WeChat / Mini Program

- [WeChat Mini Program Open Documentation](https://developers.weixin.qq.com/miniprogram/dev/framework/): API and framework documentation. Search within it for the current user privacy, network, account, and capability guidance that applies to the feature.
- [Mini Program filing operation guide](https://developers.weixin.qq.com/miniprogram/product/record_guidelines.html): use for filing steps and current filing materials; verify current status and prompts in the Mini Program console.
- [WeChat Official Accounts Platform](https://mp.weixin.qq.com/): logged-in console for主体 details, personal主体 category availability and qualifications, privacy-protection guideline,备案, code submission, review result, and release status.
- [WeChat Mini Program platform operation specifications](https://developers.weixin.qq.com/miniprogram/product/): locate the current operational rules and review rejection guidance from the official product documentation index. Do not assume an old mirrored copy is current.

## Government sources

- [MIIT: filing for mobile Internet applications](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html): policy basis and responsibilities for app/service filing, including mini-program distribution platforms.
- [CAC: necessary personal information scope for common app types](https://www.cac.gov.cn/2021-03/22/c_1617990997054277.htm): states that mini programs are within scope and explains necessary-information principles.
- [CAC: personal information protection policy FAQ](https://www.cac.gov.cn/2026-01/09/c_1769688003183197.htm): a current FAQ entry point; confirm applicable laws and later updates before relying on it.
